# 白饭鱼 v0.9.5

**修好了立绘上那道白色贴纸边，还有头发缝里的两块白。**

## 这次修了什么

### 1. 外圈那道白描边

她原本带一圈白色贴纸描边。在浅色背景上看不出来，
但她浮在别人 App 上面时背景可能是深色的 —— 那道边就成了一条孤零零的亮线，**像贴纸没撕干净**。

### 2. 头发缝里两块不透明白

她两缕头发之间本来有两道缝，**那里应该能透出后面的东西**。
原图透着白色背景，抠图的时候被填成了不透明白色 —— 看着就是不干净。

这块不好修：它**不在剪影最外圈**（外面还包着一缕很细的头发），
所以"削边缘"碰不到它，而"按形状自动找"试了几版都会误伤白围裙和白褶边。
最后按实测坐标精确切：

```
basin（饭盆头）: (843,508)  (135,538)  (872,670)  (112,723)
maid （女仆装）: (707,582)   (94,610)  (744,707)  (100,609)
```

只切框内**发亮**的像素，所以碰不到深蓝的头发。

### 怎么修的（这版的关键）

前几版我用的是"把 alpha 往里腐蚀几像素"—— **这个做法不分亮暗，一刀切**，
结果把她几缕很细的头发也削瘦了，看着就不对。

这版改成**只降"亮"像素的 alpha**：

| | 亮度 |
|---|---|
| 白色描边 | `lum ≈ 255` |
| 她的深蓝头发 | `lum ≈ 25` |

阈值卡在 215，**头发天然不在范围内，一根都不会动**；白褶边因为同属亮色会被碰到一点点，
但它内侧还是亮的，实测保留完整。
